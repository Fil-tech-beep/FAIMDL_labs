# FAIMDL Labs

A collection of practical deep learning labs, with Jupyter notebooks,
Python code, and supporting course materials.

## Topics

- **Lab 1:** Datasets and data loaders
- **Lab 2:** Building and training a custom model
- **Lab 3:** Organizing a training and evaluation project
- **Lab 4:** AlexNet and ResNet
- **Lab 5:** Transfer learning

Includes experiments with Tiny ImageNet.
Dataset ZIP archives need to be extracted before running the relevant labs.

> The scripts may contain swear words / insults for the true original student experience
